# Basic Project Agent Guide

This is a toy project used to demonstrate PlzDo.

## Rules

- Follow the root `AGENTS.md` first.
- Keep changes small and evidence-backed.
- Do not use live APIs or credentials.
- Run `./scripts/verify` before claiming completion.

## Source Order

1. Latest user request.
2. `TASKS/current.md`.
3. `docs/requirements.md`.
4. `docs/technical-design.md`.
5. `CHECKS.md`.
6. Code and tests.
